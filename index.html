硬件损坏、勒索攻击、误操作，所需的恢复方式各不相同。BareTurn 在同一个控制台中提供全部恢复方式。

产品功能

从日常备份到整机重建，所有功能都包含在每一份许可中。

整机与裸机恢复

内置启动介质构建器，生成 WinPE 和 Linux 恢复 ISO。按原始偏移和 GUID 重建 GPT/UEFI 与 MBR/BIOS 分区，异机恢复时可注入驱动。

分区即时恢复

Windows 通过本机 iSCSI、Linux 通过 dm-clone 挂载恢复点，数秒内可读写。热数据按需读取，后台限速回写，重启后自动继续。

离线盘与不可变副本

自动同步到可引导 USB 离线盘，完成后安全弹出。可将恢复点复制到 S3 兼容存储，并启用 Object Lock 合规或治理模式。

无驱动增量备份

不安装内核过滤驱动。NTFS 通过 USN 日志与 MFT 跟踪变化，Linux 跳过空闲块；Zstandard 压缩，SHA-256 源端去重，多连接并行传输。

文件级恢复

只读挂载任意恢复点，按目录浏览和下载，或写回任一受保护计算机；也可通过 WebDAV 映射为本地盘符。

集中管理与告警

在 Web 控制台中统一管理计算机、计划和存储库。支持三级角色权限，以及企业微信、钉钉、飞书和 Syslog 告警。

备份系统本身也需要防护

攻击者往往会先删除备份。BareTurn 从架构上减少可被利用的环节。

由 Core 发起备份

受保护计算机不保存存储库路径和凭据，被攻陷的终端无法删除备份。

不保存系统密码

一次性配对后使用证书指纹固定和随机令牌通信，系统密码不落盘。

数据全程加密

存储库与离线盘使用 AES-256-GCM 加密，传输使用 TLS。

离线签名许可

许可文件使用 ECDSA P-256 签名，在本地校验，不需要连接厂商服务器。

访问控制

三级角色权限，支持在本地运行的 TOTP 双因素认证。

配置可迁移

Core 配置可加密导出，在新硬件上恢复后自动进入 30 天迁移宽限期。

Core、Agent 与存储库三层分离。Core 负责调度、拉取数据和发起恢复。

常见问题

关于许可、试用和部署的常见问题。

终身免费更新（Lifetime Updates）包含什么？以后有续费吗？

没有任何年度续订或版本升级费。一次购买后，您永久拥有软件使用权，并可终身免费获取 BareTurn 后续所有版本更新与系统适配补丁（包含基础邮件与文档支持）。如需大型企业专属 7×24 应急响应 SLA，可另行签订支持协议。

试用到期后，已经备份的数据还能恢复吗？

可以。无论试用是否到期，所有恢复点都可以进行裸机恢复、离线盘恢复、分区恢复、挂载浏览和文件下载。

机房完全断网，可以激活和使用吗？

可以。在内网的 Core 控制台导出请求文件（.req），用任意能上网的设备在许可门户换取许可文件（.bareturnlic），再拷回内网导入即可。之后无需连接外网。

Core 服务器硬件故障或需要迁移怎么办？

许可与三项稳定的硬件特征绑定，其中任意两项匹配即视为同一台机器，不绑定网卡 MAC 或数据盘序列号，日常维护不会导致许可失效。整机迁移或在新硬件上恢复 Core 配置后，系统自动进入 30 天迁移宽限期，备份和恢复不受影响，您可在此期间通过许可门户自助换绑。

退役的计算机会一直占用许可吗？

不会。在控制台中对计算机执行“停止保护”后，它会转为已归档状态并立即释放许可，可分配给其他计算机。已有的恢复点会完整保留，仍可挂载和恢复。
